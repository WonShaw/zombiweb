# 死亡之夜 · 丧尸模式

仿《使命召唤》丧尸模式的第一人称生存游戏，用 Three.js + TypeScript + Vite 编写，在浏览器里运行（Mac 上 Safari / Chrome 均可）。

所有模型、贴图、音效都是运行时程序化生成的，没有外部素材文件。

## 运行

```bash
npm install
npm run dev
```

然后用浏览器打开 <http://localhost:5173>，在主菜单选地图，点击「开始游戏」。也可以直接用网址选地图：`?map=manor`（废弃庄园）或 `?map=lab`（城市研究中心）。

打包成静态文件：`npm run build`，产物在 `dist/`。

## 操作

| 按键 | 作用 |
|---|---|
| W A S D | 移动 |

| Esc | 暂停 |

## 玩法

- 丧尸从窗户外爬出来，拆掉木板后翻窗进屋。丧尸分三种，同一种的属性固定不变，不会随回合变强；回合越高，丧尸越多、精英和超精英的比例越高：

  | 种类 | 外观 | 血量 | 攻击 | 移动 | 拆板（秒/下） | 击杀额外加分 |
  |---|---|---|---|---|---|---|
  | 普通丧尸 | 破衣服、橙黄眼睛 | 150 | 35 | 慢走 | 1.4 | 0 |
  | 精英丧尸 | 钢盔 + 军装、红眼，体型大一圈 | 700 | 50 | 小跑 | 1.0 | +40 |
  | 超精英丧尸 | 铁面具 + 胸甲、紫色发光裂纹，体型最大 | 2500 | 75 | 冲刺 | 0.7 | +100 |

  比例：第 1–4 轮全是普通丧尸；第 5 轮开始出精英（每轮 +5%，最多 50%，第 14 轮封顶）；第 10 轮开始出超精英（每轮 +4%，最多 30%，第 17 轮封顶）。每种第一次出现时屏幕上会提示。
- 积分：击中 +10，击杀 +60，爆头 +100，刀杀 +130，电网、铁丝网或自动机枪击杀 +50，自动机枪打中 +10，修一块木板 +10。连杀奖励：3.5 秒内连续击杀，从双杀起每多一杀额外 +20（双杀 +20、三杀 +40……封顶 +100），只算玩家自己的击杀。
- 弹药无限，只需要换弹。
- 两张地图，主菜单里选（会记住上次的选择）：
  - **死亡之夜 · 废弃庄园**（夜晚，单层）：7 个区域，每开一扇门只多出 0～2 扇窗，越往里门越贵。起始房间（3 窗）→ 西南（神秘箱）/ 东南（Speed Cola），750，各 2 窗 → 西北（Double Tap）/ 东北，1000，各 2 窗 → 北廊，1000，2 窗 → 饮料房（Juggernog），1250，没有窗、只有一个入口。
  - **白昼危机 · 城市研究中心**（白天，两层）：现代研究大楼，四周是广场、马路和城市楼群，阳光从玻璃幕墙和中庭天窗照进来（有实时阴影）。
    - 起点是一楼大厅，中间一座大楼梯直通二楼回廊（回廊绕着挑空中庭，和大厅算同一个区域）。起点共 3 扇窗：大厅南面 2 扇 + 回廊南面 1 扇。
    - 一楼：大厅 → 生物实验室（神秘箱）/ 员工餐厅（Speed Cola），750，各 2 窗 → 北侧后勤通道（Double Tap），从实验室或餐厅开门，1000，2 窗。
    - 二楼：回廊 → 计算机房 / 办公区，1000，各 2 窗；实验室和餐厅里各有一道侧楼梯门（1000）也能上去，形成上下两层的环路 → 主任实验室（Juggernog），1250，没有窗。
    - 二楼的窗户外搭着施工脚手架：丧尸先走到梯子底下，爬上脚手架，再在跳板上拆板翻窗。爬梯子时打死会掉回地面。
    - 楼梯是连续斜坡，走上走下都顺畅；回廊边、楼梯井和楼梯侧面有玻璃栏杆，掉不下去。子弹能从二楼打到一楼（楼板、楼梯会挡子弹），玻璃幕墙和玻璃隔断是防弹玻璃。丧尸会按楼层寻路，只能走楼梯上下楼；楼上楼下隔着楼板打不到你，你也够不着楼上楼下的门、饮料机和掉落道具。
    - 机枪可以放在二楼，但不能放在楼梯上。
  - 所有已开通区域的窗户都会来丧尸，离你近的窗户（尤其是你所在区域、同一层的）出得更多一些。
- 用积分开门（750–1250）、抽神秘箱（950）、喝饮料：
  - Juggernog（2500）：生命值提升到 250
  - Speed Cola（3000）：换弹速度翻倍
  - Double Tap（2000）：射速提升 33%
- 掉落道具：Insta-Kill、Double Points、Nuke、Carpenter（修好所有窗户）、Fire Sale（神秘箱 10 分）。

### 打击反馈

- 伤害数字：命中处弹出数字，普通为白色、爆头为橙红色大字、致死一击放大发光；霰弹枪同一枪的弹丸会合并成一个数字；自动机枪和电网的数字较小。
- 击杀徽章：屏幕中下方显示本轮击杀图标（爆头、普通、刀杀、爆炸、闪电各有图标），3.5 秒内连续击杀算连杀，显示「双杀、三杀……七杀、N 连杀」和这次的连杀奖励积分。只有玩家亲手的击杀计入连杀。
- 音效：命中身体是闷响，爆头命中是金属脆响；击杀有低音一击加铃声，连杀越多音调越高，达成连杀时还有一段和弦。
- 丧尸出生时随机一种固定姿势（经典伸手、佝偻驼背、后仰、单手垂下、歪脖扭身、高举双手、拖腿），挨枪不会改变，走路时上半身不晃，转身有速度上限，方便瞄准；屋里的丧尸挨打会被轻微击退，致死一击会把尸体击飞，霰弹枪、狙击枪和爆炸飞得更远。

**机枪**：两种，数量不限，都会自动转向扫射看得见的丧尸；打空后走过去短按 F 上弹，有子弹时不能上弹。头顶有弹药条，打空时闪红；屏幕左上角会列出没子弹的机枪（种类、编号、距离、指向箭头）。

| 种类 | 价格 | 弹匣 | 每发伤害 | 射速 | 射程 | 上弹 | 穿透 |
|---|---|---|---|---|---|---|---|
| 自动机枪 | 10000 | 200 | 110 | 600 发/分 | 20 米 | 2.5 秒 | 无 |
| 重型机枪 | 20000 | 400 | 200 | 500 发/分 | 24 米 | 3.5 秒 | 1 只（第二只伤害 ×0.7） |

- 机枪升级（对所有机枪生效，包括以后买的，各一级）：
  - 弹匣扩容（40000）：弹匣翻倍（自动机枪 400、重型机枪 800）；已部署的机枪不会自动补满，打空后上弹时装满。
  - 威力强化（40000）：每发伤害翻倍（自动机枪 220、重型机枪 400）。
  - 自动装弹（100000）：打空后自己上弹，不用走过去按 F；没打空不会提前上弹。

- 放置：在商店买下后回到游戏，面前会出现半透明虚影（绿色可放、红色放不下），按左键或 F 放下，右键取消并退还积分。
- 搬动：对着已放下的机枪按住 F 约 0.8 秒搬起来，剩余弹药保留；右键取消会放回原位。搬运时不能开枪。

**路障升级**：对所有窗户生效。升级路障材质时，所有窗户会立刻换上新材质并补满。

- 子弹、自动机枪都能穿过路障打到窗外的丧尸（打不坏路障）；被木板 / 钢板挡住的丧尸会显示半透明的透视轮廓（颜色和眼睛一样：普通橙黄、精英红、超精英紫），只透过路障，不透墙。

- 路障材质（逐级升级，每级每块板多拉一下）：普通木板（初始，1 下）→ 厚木板（800，2 下）→ 带铆钉厚木板（1500，3 下）→ 普通钢板（2500，4 下）→ 加厚钢板（3500，5 下）→ 带铆钉加厚钢板（5000，6 下）→ 带铁丝网的铆钉加厚钢板（7000，耐久同上，丧尸每拉一下被扎掉 20 点生命值）。
- 电网：电击陷阱（2000）每扇窗每 8 秒电一次拆板的丧尸，300 伤害；高压电网（4000）每 5 秒一次，800 伤害；两级都会定住丧尸 0.8 秒。
- 电网和铁丝网都是固定伤害，丧尸越强越扛得住：普通丧尸被 1 级电网一下电死、在铁丝网上拽 8 下被扎死；精英要 3 下 1 级 / 1 下 2 级电网；超精英要 4 下 2 级电网，铁丝网基本扎不动它。
- 自动修复：修理工具（1000）每 12 秒补一块板；自动钉枪（2500）每 6 秒补一块。
- 电网和铁丝网扎死丧尸各 +50 分，扎到但没死不加分。

## 代码结构

```
src/
  game.ts              主循环、回合流程、积分
  hud.ts               界面（DOM）
  shop.ts              商店页面（武器、自动机枪、路障升级、离屏渲染的缩略图）
  core/                输入、Web Audio 合成音效、程序化贴图（labTextures.ts 是研究中心用的）
  world/map.ts         地图数据结构、地图列表、废弃庄园的布局
  world/labMap.ts      城市研究中心的两层布局（楼梯、挑空、玻璃墙、家具、门、窗）
  world/level.ts       关卡核心：最多两层的格子地图、楼梯斜坡、按高度的碰撞、子弹射线、按楼层的寻路流场
  world/labScene.ts    研究中心的外观：墙地顶、楼梯和栏杆、天窗、家具、脚手架、室外城市、太阳和阴影
  world/interactables.ts  门、饮料机、神秘箱、修窗
  world/turrets.ts     可部署的自动机枪
  world/powerups.ts    掉落道具
  entities/            玩家、丧尸模型与 AI
  weapons/defs.ts      武器、饮料、路障升级数据
  weapons/melee.ts     近战武器：数据、模型、挥砍关键帧
  weapons/models.ts    37 把枪的程序化枪模（侧面轮廓挤出、回转体、准星照门对齐开镜；击锤等零件都低于照门缺口，开镜不挡准星）
  weapons/parts.ts     枪模零件库：木纹 / 金属材质、握把、扳机护圈、弹匣、按材质合并
  weapons/             射击逻辑、能量弹 / 火箭弹
  fx/                  粒子、弹孔、血迹、闪电、伤害数字与击杀徽章、路障透视轮廓
```

调试：浏览器控制台里的 `game` 是游戏实例；`game.debugStart()` 可以不锁鼠标直接开始，`game.debugStep(秒)` 手动推进模拟。
